# INT8 点积加速器最小设计规格

## 目标

第一阶段实现一个与总线协议解耦的四路有符号 INT8 点积核心：

```text
result = a0*b0 + a1*b1 + a2*b2 + a3*b3
```

它是后续“PicoRV32 + CSR/AXI + 中断 + 软件驱动”项目的计算内核。

## 接口

| 信号 | 方向 | 位宽 | 含义 |
|---|---|---:|---|
| `clk` | 输入 | 1 | 上升沿时钟 |
| `rst_n` | 输入 | 1 | 低有效同步复位 |
| `start` | 输入 | 1 | 空闲时拉高一周期以提交请求 |
| `vector_a` | 输入 | 32 | 四个有符号 INT8，lane 0 位于 `[7:0]` |
| `vector_b` | 输入 | 32 | 四个有符号 INT8，lane 0 位于 `[7:0]` |
| `busy` | 输出 | 1 | 运算进行中；此时新的 `start`被忽略 |
| `done` | 输出 | 1 | 结果有效的单周期脉冲 |
| `result` | 输出 | 32 | 有符号点积结果 |

## 微架构

```text
输入锁存 → 四路并行 8x8 有符号乘法 → 符号扩展并累加 → 结果寄存器
```

从接受 `start`到 `done`经历两个后续时钟边沿。输入、乘法、累加分别处于独立逻辑阶段，为后续提高频率和扩展 lane 数量保留空间。

## 数值范围

单个有符号 INT8的范围为 `[-128, 127]`。四个乘积的理论结果范围可由 18 位有符号数覆盖；接口使用 32 位结果，便于软件访问并为未来增加 lane 数量留余量。

## 第一阶段验收条件

- Vivado/XSim编译与展开无错误。
- 定向测试覆盖零、正负混合和极值。
- 1000组随机向量与 testbench参考模型一致。
- 验证 busy期间的第二个 start不会覆盖当前操作。
- 验证复位能够终止正在执行的操作，且复位后可以继续工作。
- 针对 PYNQ-Z2器件完成独立综合，并满足 100 MHz时钟约束。

## 本阶段明确不包含

- AXI4-Lite从机和 CSR寄存器映射。
- CPU到加速器的地址译码。
- 中断控制器。
- RISC-V GCC软件编译。
- FPGA下载与板级验证。

这些功能属于下一阶段。先验证计算内核，可以显著缩小总线集成时的排错范围。
